# 社内備品管理ページ（/bihin）セットアップ手順

合言葉を知っている社内メンバーだけが使える備品管理ページです。
**すべて無料枠のサービスだけで動きます（追加課金なし）。**

| 役割 | サービス | 無料枠 |
|---|---|---|
| ページのホスティング | Vercel（現行のまま） | Hobby プラン |
| 備品データ・写真の保存 | Upstash Redis（Vercel Marketplace） | 無料プラン（予約・問い合わせと同じインスタンスを共用） |

## できること

- **URL**: `https://kabuexlabs.com/bihin/`
- 合言葉（`BIHIN_ADMIN_KEY`）でログイン。ログイン状態はブラウザを閉じるまで保持されます（合言葉はURLに載らない安全な方式です）
- 備品ごとに以下を登録・編集できます
  - アイテム名
  - 個数（一覧の「＋／−」ボタンでも増減できます）
  - 写真（スマホで撮ったままの写真でOK。ブラウザ側で自動縮小してから保存します）
  - 購入価格（不明なら空欄でOK。「不明」と表示されます）
  - 保管場所
  - いつ・何の用途で買ったか（任意・自由記述のメモ）
- 一覧は名前・保管場所・メモの内容でしぼり込みできます
- 備品の削除もこのページからできます（写真も一緒に消えます）
- 検索エンジンには載りません（noindex ヘッダー付き・サイトマップ非掲載）。写真もログインしていないと見えません

## 初回セットアップ（5分ほど）

### 1. データベース（Upstash Redis）

予約システム（docs/yoyaku-setup.md）ですでに接続済みならそのまま使えます。
未接続の場合：

1. [Vercel ダッシュボード](https://vercel.com/dashboard) → このプロジェクト → **Storage** タブ
2. **Create Database** → **Upstash (Redis)** を選択 → **Free** プランで作成
3. プロジェクトに Connect すると環境変数（`KV_REST_API_URL` / `KV_REST_API_TOKEN`）が自動で追加されます

### 2. 環境変数を設定する

Vercel ダッシュボード → プロジェクト → **Settings → Environment Variables** で以下を追加します。

| 変数名 | 値 |
|---|---|
| `BIHIN_ADMIN_KEY` | 備品管理ページの合言葉（十分長い推測されにくいもの。予約管理の合言葉と別でも同じでも可） |

### 3. 再デプロイ

環境変数を追加したら **Deployments** から最新デプロイを **Redeploy** して反映します。
その後 `https://kabuexlabs.com/bihin/` を開き、合言葉でログインできれば完了です。

## 補足

- 写真は長辺1000pxのJPEGに自動縮小して保存するため、1枚あたりおよそ100〜300KBです。Upstash 無料枠でも数百点は問題なく保存できます
- JavaScript が無効なブラウザでは自動縮小が働かないため、550KB以下の写真のみアップロードできます
- ログイン失敗が10分間に5回続いたIPは一時ロックされます（予約・問い合わせ管理と共通の総当たり対策）
