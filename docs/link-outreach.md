# 被リンク依頼リスト（2026-09-06 作成）

被リンクはゼロではない（電ファミニコゲーマー2記事・PR TIMES・note・日経掲載）が、量と集まり先は未確認。ヘッド語（イマーシブ／マダミス／頭脳戦／心理戦／施設活用）で上位を狙うには第三者からの言及を増やす必要がある。
サイト内に実在の関係が残っている相手だけに絞り、「置く場所を相手が持っているか」×「通りやすさ」で3段階。

## 優先の考え方（2026-09-07 FB反映）
1. 施設公式サイトのイベント紹介に「企画・制作：株式会社ex Labs」として掲載してもらう（渋谷サクラステージ、サーマルクライムスタジオ、紀伊國屋書店）

- リンク文言はキーワード一律指定ではなく、会社名・企画名・担当内容に合わせる（例：「企画・制作：株式会社ex Labs」）。
- 先に GSC のリンクレポートで既存被リンクの集まり先を確認し、そのページから法人向けページへの導線を整える。
