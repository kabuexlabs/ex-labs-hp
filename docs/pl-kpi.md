# 店舗事業 月次PL・KPI計画（売上150万円モデル）

マダミス・人狼・シーシャ店舗の月次損益計画（PL）と、売上150万円/月に向けたKPIです。
**単価・回数・人数などの前提はすべて仮置き**です。`docs/pl-simulator.html` をブラウザで開くと、
数値を変えながらリアルタイムでPL・KPIを再計算できます。

- 初期費用（内装・敷金礼金・機材等）は含みません
- オーナー報酬・税金・減価償却も含みません（営業利益ベース）
- ①〜④の単価は想定値です。確定したら差し替えてください

## 収益モデル（月間・想定）

収入規模の想定順: **④人狼 > ③マダミス(ライセンス) > ①パンドラ人狼・②マダミス(自作) > ⑤シーシャ > ⑥ドリンク**

|---|---|---:|---:|---:|---:|
| ④ | 人狼 | 3,000円 | 16回 | 10人 | 480,000円 |
| ③ | マダミス（ライセンス） | 5,000円 | 12回 | 7人 | 420,000円 |
| ① | パンドラ人狼（自作） | 4,000円 | 8回 | 6人 | 192,000円 |
| ② | マダミス（自作） | 4,500円 | 7回 | 6人 | 189,000円 |
| ⑤ | シーシャ | +2,000円/回 | 90回 | ― | 180,000円 |
| ⑥ | ペットボトルドリンク | 200円/本 | 300本 | ― | 60,000円 |
| | **合計** | | 43公演 | 延べ334人 | **1,521,000円** |

- シーシャは公演参加者へのクロスセル想定（延べ来店の約27%が利用）
- ドリンクは原価150円/本のためほぼ利益なし（売価200円と仮置き）

## KPI（売上150万円に向けた月次目標）

売上の分解: **売上 = 延べ来店人数 × 客単価（約4,550円、シーシャ・ドリンク込み）**

| KPI | 月次目標 | 根拠・メモ |
|---|---:|---|
| 月間来店人数（延べ） | 334人 | 公演参加の延べ人数 |
| リピート率 | 40% | リピート約134人／新規約200人 |
| 新規来店人数 | 200人 | 延べ来店 ×（1−リピート率）。SNS・イベント経由で獲得 |
| SNS登録人数（純増） | +150人/月 | 来店者の約45%が登録する想定 |

| シーシャ利用率 | 27% | 延べ来店に対する利用割合（90回） |

### KPIの優先順位（このモデルでの感度）

1. **④人狼と③ライセンスマダミスの開催数×集客人数** — 売上の6割を占める2本柱
2. **リピート率** — 新規200人/月をずっと獲り続けるのは重いので、リピート率が上がるほど新規目標が下がる
3. **シーシャ利用率** — 原価率25%で利益率が高く、深夜稼働率と連動
4. **SNS登録人数** — 新規→リピート転換の中間指標

## 前提の変更方法

`docs/pl-simulator.html` をブラウザで開くと、単価・回数・人数・ライセンス料率・家賃などを
入力欄で変更して、PL・KPI・損益分岐点をその場で再計算できます（外部依存なしの単一ファイル）。
