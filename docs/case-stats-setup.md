# 謎解きアプリ統計（/case/admin）セットアップ手順

展示型謎解きアプリ（/case/）の参加状況を集計・閲覧する管理ページです。
**予約システム（/yoyaku）と同じ無料枠のデータベースを使うため、新しいアカウント登録は不要です。**

## 見られるデータ

- 参加者数（調査を開始した端末数）／1問以上回答した端末数／完走数・完走率
- 参加者全体の平均正答率、探偵ランクの分布
- 真相（最終問題）への到達率・解明率
- 問題ごとの「挑戦者数・解決者数・正答率・平均回答回数・ヒント使用者数」
  （どの問題が難しすぎた・易しすぎたかが一目で分かります）
- CSVダウンロード（Excel・スプレッドシートでそのまま開けます）

数値は各端末から**匿名IDで自動送信される進捗の集計**で、氏名などの個人情報は一切含まれません。

## セットアップ

### 1. データベース（すでに予約システムを使っている場合は不要）

/yoyaku のセットアップ（docs/yoyaku-setup.md）で Upstash Redis を接続済みなら、
そのまま同じデータベースを共用します。**追加作業はありません。**

未接続の場合のみ:

1. [Vercel ダッシュボード](https://vercel.com/dashboard) → このプロジェクト → **Storage** タブ
2. **Create Database** → **Upstash (Redis)** → **Free** プランで作成し、プロジェクトに Connect

### 2. 管理ページの合言葉を設定する

Vercel ダッシュボード → プロジェクト → **Settings → Environment Variables** で追加:

| 変数名 | 値 |
|---|---|
| `CASE_ADMIN_KEY` | 管理ページの合言葉（十分長い推測されにくいもの） |

追加後に再デプロイすると有効になります。

## 使い方

- 管理ページ: `https://kabuexlabs.com/case/admin/`（検索エンジン非掲載・合言葉ログイン）
- 集計はページを開いた時点の最新値。再読み込みで更新されます
- **統計をリセット**ボタンで全データを削除できます（イベント本番前に、テスト期間の
  データを消してから開場するのがおすすめです）
- 来場者側の `/case/dev/` で「進捗をリセット」すると、その端末の統計記録も一緒に
  消えます（テスト端末が本番の集計を汚しません）

## 仕組みと制限

- 各端末は回答・ヒント使用のたびに、自分の進捗全体を `/api/case/track` へ送信します
  （数秒のデバウンス付き）。同じ端末は常に上書き保存されるため、再送・重複で
  数字が壊れることはありません
- 送信は best-effort です。圏外・省電力などで届かなかった分は、次に何か操作した
  タイミングで最新状態がまとめて反映されます
- ブラウザのサイトデータを消した端末は別の参加者として数え直されます
