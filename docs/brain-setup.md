# 第二の脳（/brain）セットアップ手順

名刺・議事録・メモを1か所に貯めて、あとから横断検索で引っ張り出す社内システムです。
「自分の外部記憶」として、次の3経路で情報を入れられます。

- **手入力** … フォームからそのまま
- **口頭（音声入力）** … 🎙ボタンで話すと本文に文字起こしが追記される
  （ブラウザ内蔵の Web Speech API。音声データは自社サーバーに送られません）
- **PDF取り込み** … PDFを選ぶとサーバー側でテキストを抽出して記録として保存
  （ファイル自体は保存せず、抽出テキストだけ残る。4MBまで）

入れたものはすべて `/brain/` の横断検索（表記ゆれに強い正規化つき・AND検索）で
引っ張り出せます。名刺の氏名を議事録の「関係者」や本文に書くと、名刺詳細に
関連ノートとして自動で並びます。

## ページ構成

| URL | 内容 |
|---|---|
| `/brain/` | ログイン・横断検索・最近の記録・操作ログ |
| `/brain/contacts/` | 名刺の一覧・登録・編集・削除 |
| `/brain/notes/` | 議事録・メモの一覧・作成（音声入力）・PDF取り込み・編集・削除 |
| `/brain/export.json` | 全データのJSONバックアップ（ログイン必須） |

## 必要な環境変数（Vercel のプロジェクト設定に登録）

| 変数 | 内容 |
|---|---|
| `BRAIN_ADMIN_KEY` | ログインの合言葉。`openssl rand -base64 24` などで生成した長いランダム文字列にする |
| `KV_REST_API_URL` / `KV_REST_API_TOKEN` | Upstash Redis（予約システムと共用。すでに設定済みなら追加作業なし） |

Upstash Redis をまだ入れていない場合は、Vercel ダッシュボード → Storage →
Marketplace から Upstash Redis（無料プラン可）を追加すると、上記2変数が
自動で注入されます。

## セキュリティ設計（実装済みの対策）

- 合言葉は **POSTでのみ** 受け取り、URL・クエリには一切載せない（履歴やアクセスログに残さない）
- 照合はタイミングセーフ比較（`crypto.timingSafeEqual`）
- Cookie に入るのは合言葉ではなく、**KVに保存したランダム256bitのセッショントークン**
  （12時間で自動失効・使用中は延長・ログアウトで即失効）。
  Cookie は `HttpOnly` / `Secure` / `SameSite=Strict` / `Path=/brain`
- ログイン試行は **IPごとに15分10回まで**（総当たり対策。IPはハッシュ化して保存）
- すべての変更系POSTで **Originヘッダ検証**（SameSite=Strict と二重のCSRF対策）
- 出力はAstroの自動エスケープに統一（`set:html` 不使用）でXSSを遮断。
  サイト全体のCSP・`X-Frame-Options: DENY` 等のヘッダも適用される
- PDFはマジックバイト（`%PDF-`）とサイズ上限を確認してからテキスト抽出のみ実施。
  アップロードされたファイル自体はどこにも保存しない
- `/brain` 配下は `noindex` + `Cache-Control: no-store`（検索エンジン・共有キャッシュに残さない）
- 入力値はすべて項目ごとの長さ上限つきで受け付け

## データとバックアップ

- 保存先は Upstash Redis（`brain:contacts` / `brain:notes` / `brain:log`）
- 登録・更新・削除の操作履歴が `/brain/` の「操作ログ」に残る（直近500件）
- `/brain/export.json` でいつでも全件JSONダウンロードできる。
  定期的に手元へ保存しておくと安心

## 音声入力の対応ブラウザ

Chrome / Edge / Safari（iOS含む）。Firefox は Web Speech API 未対応のため
ボタンが無効表示になります。初回はブラウザがマイク許可を求めます。

## PDF取り込みの注意

- 文字情報を持つPDF（Word等から書き出したもの、OCR済みのもの）が対象。
  スキャン画像だけのPDFは文字が取れないためエラーになります
- 4MB超は Vercel のリクエスト上限にかかるため、分割してから取り込む
- 抽出テキストは1件あたり10万文字まで（超過分は切り詰めた旨を明記して保存）
