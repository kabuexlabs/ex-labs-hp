# 街歩き謎解きイベント（/shimokita）セットアップ・運用手順

下北沢の街全体を舞台にした、街歩き型謎解き・探偵体験イベント用のWebアプリです。
プレイヤーはスマホのブラウザからURL（またはQRコード）でアクセスするだけで遊べます。
アプリのインストールは不要です。

**すべて既存の無料インフラ（Vercel + Upstash Redis）だけで動きます。**

## URL

| 用途 | URL |
|---|---|
| プレイヤー用 TOP（QRコードにするURL） | `https://kabuexlabs.com/shimokita/` |
| プレイ画面 | `https://kabuexlabs.com/shimokita/play/` |
| 運営管理画面 | `https://kabuexlabs.com/shimokita/admin/` |

すべて noindex（検索エンジン非掲載）です。

## 初回セットアップ

1. **Upstash Redis** — 予約システム（/yoyaku）と共用です。すでに
   `KV_REST_API_URL` / `KV_REST_API_TOKEN` が設定されていれば追加作業はありません。
   （データは `smk:` プレフィックスで分離されています）
2. **管理画面の合言葉** — Vercel の環境変数に `SMK_ADMIN_KEY` を追加します。
   未設定の場合は `YOYAKU_ADMIN_KEY` がそのまま使えます。
3. デプロイ後、`/shimokita/admin/` にアクセスすると、**サンプルシナリオ
   「下北沢クロニクル 消えた劇作家」（STEP×3＋最終推理、サンプル店舗×5）**が
   自動投入されます。これを土台に、管理画面から実際の内容に差し替えてください。

## ゲームの構造

```
TOP → 開始（参加コードは設定時のみ要求）
 → STEP: ストーリー → 謎解き → マップ解放 → 店舗訪問（キーワード/コード入力で確認）
   → 証拠獲得 → 次のSTEP …
 → 最終推理 → エンディング（CASE CLOSED）
```

- **店舗と物語の分離（最重要思想）**: STEPは特定の店舗に紐付かず、
  「候補店舗グループ＋必要訪問数」を持ちます。当日休業の店舗は候補から
  自動的に消え、営業店舗数が必要訪問数を下回った場合は必要数が自動的に
  下がるため、**店が休んでもゲームが進行不能になりません**。
- **進行データ**: プレイヤーはCookie（30日）で識別され、ページを閉じても
  同じ端末から再開できます。正誤判定はすべてサーバー側で行い、答えは
  ブラウザに送信されません。

## 管理画面でできること（すべて再デプロイ不要・即時反映）

- **ダッシュボード**: 当日の営業店舗一覧（ワンタップで OPEN / 本日休業 /
  一時利用停止 / 混雑受付停止 に変更）、現在プレイ中・本日開始・本日クリアの人数、
  STEP別到達・誤答・ヒント数、店舗別訪問数（提携店舗への成果報告に使えます）
- **店舗**: 追加・編集・削除、座標、席利用可否、購入商品と価格、店舗ミッション、
  訪問確認方式（キーワード/店舗コード）と正解コード、獲得できる証拠、
  週間営業スケジュール、特定日の例外設定
- **STEP・謎**: STEPの追加・並び替え・削除、ストーリー、問題文・正答・別解・
  正解演出文、段階ヒント、候補店舗グループと必要訪問数、
  **緊急スキップ**（店舗トラブル時に全プレイヤーの店舗フェーズを省略可能にする）
- **プレイヤー**: 一覧・詳細、STEP移動、店舗フェーズのクリア扱い、
  特定店舗の訪問付与（証拠も渡す）、最終推理へ送る、リセット、削除
- **設定**: イベントタイトル、参加コード（空欄なら誰でも開始可）、注意事項、
  最終推理の問いと正答、エンディング

## 当日の運用フロー（例）

1. 朝、`/shimokita/admin/` を開き、当日の営業店舗を確認・調整
2. 店舗から「今日は休みます」と連絡が来たら、ダッシュボードでワンタップで
   「本日休業」に変更 → 以降マップに表示されなくなります
3. 特定のプレイヤーが店舗トラブルで詰まったら、プレイヤー詳細から
   「店舗フェーズをクリア扱い」または「訪問付与」で救済
4. イベント後、ダッシュボードの店舗別訪問数を提携店舗への報告に使用

## 回答の表記ゆれについて

謎・キーワードの照合は、全角/半角・大文字/小文字・カタカナ/ひらがな・
空白の有無を自動で同一視します（例:「シモキタ」=「しもきた」=「ｼﾓｷﾀ」）。
それ以外の別解（漢字表記など）は管理画面の「別解」欄に1行ずつ登録してください。

## 地図について

地図は OpenStreetMap（無料・APIキー不要）を使用しています。店舗詳細から
Googleマップアプリへのリンクも自動生成されます。

## 将来拡張の足場

QRコード確認（コード入力と同じ仕組みにキーワード付きURLで載せられます）、
GPS連動（位置情報の許可ヘッダーは設定済み）、LINE風ストーリー、複数エンディング
などは、現在のデータ構造のまま追加できます。
