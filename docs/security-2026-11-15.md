背景：Google の November 2026 core update（11/10 開始・最大2週間）。Google は新しい方針を出していないため、
「表示内容は変えず、裏側（速度・レイアウトのずれ・安全性）を整える」範囲で対応した。順位への効果は断定しない。

### 依存パッケージ（npm audit：24件）— 更新は未実施（ユーザー判断待ち）

自動の安全確認で、パッケージの更新が止められた（以前「astro・@astrojs/vercel は上げない」と決めているため）。影響の評価と推奨：

- **@astrojs/vercel 11.0.2 → 11.0.3（推奨・小さい）**：差分は ISR 用の入口の条件1か所だけ（パス上書きの確認にトークンを追加）。出力の形は同じ。上記の緩和で当面は防げている。
- **nodemailer 10.0.12 → 10.5 系（推奨）**：宛先解析の不具合5件。宛先の厳格化で実害の経路は塞いだ。
- **sanitize-html 2.17.5 → 2.18 系（推奨）**：ブログ本文の無害化の抜け道4件。悪用には microCMS の編集権限が必要。
- **astro 7.1.3（据え置き）**：重大1件（AVIF 画像変換の RCE）は画像変換を無効にしているため該当しない。base 未設定・View Transitions／Actions／Server Islands 未使用のため、残りの多くも該当しない。7.3 系で本番がダウンロード扱いになった経緯があるため、上げる場合はプレビューで確認してから。
- vite・sharp・svgo・js-yaml などはビルド時だけ使うもので、公開サイトの実行時には動かない。

## 2. 裏側の調整（表示内容は変えない）

- **レイアウトのずれ（CLS）**：パンくずの行の高さが Web フォント到着で 32→37px に伸び、本文全体が下にずれていた（没入感の記事で 0.27）。行の高さを到着後の値（約1.45倍）に固定（src/styles/xtone.css）。没入感の記事の CLS は計測 0.46→0.12。残りは本文の折り返しがフォントで変わるもので、フォントの読み込み方（display=optional など）を変えると初回の見た目が変わるため見送り。
- **画像の読み込み量**：サービスページの写真（横880px・100〜300KB）をスマホでもそのまま読んでいた。横600pxの縮小版を17枚作り、srcset でブラウザに選ばせる（src/data/imageVariants.ts、ServicePage）。/services/immersive/ はスマホで転送 2,848KB→2,210KB、LCP 4.8秒→3.4秒（ローカル・CPU4倍遅延・回線制限の計測）。
- 全163ページの前後スナップショットで、title・description・canonical・robots・見出し・本文・内部リンク・構造化データの差分は0。

## 3. 見送り・提案

- 依存パッケージの更新（上記）。
- フォントの読み込み方の変更（初回表示の見た目が変わるため）。
- /gensou/ の大きなKV画像（370KB）の縮小版：スマホでも全幅表示で高解像度が必要なため効果が小さく、会期も 11/22 まで。
