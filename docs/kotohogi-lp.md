- 検索対策：meta robots noindex,nofollow,noarchive＋レスポンスヘッダー `X-Robots-Tag`（ページ側と vercel.json の `/preview/(.*)`）。sitemap・llms.txt・ナビ・他ページからのリンクには載せない。
- アクセス制限：Vercel の環境変数 `KOTOHOGI_PREVIEW_PASSWORD` を設定すると Basic 認証がかかる（ユーザー名は任意、パスワードのみ照合）。**リポジトリが公開なので URL だけでは秘密にならない**。未設定の間は URL を知っていれば誰でも見られる。共有は URL とパスワードを別経路で。
- 確認用注釈：URL 末尾に `?review=1` を付けると、未確定箇所の「確認用｜…」注釈が出る（書き出しの reviewMode）。
- 冒頭演出：タップ／スキップ／Esc で終了。「動きを減らす」設定なら流さない。フッターの「オープニングをもう一度見る」で再生。
- 右下の「チケット購入」は常時固定。販売先URL未設定の間はページ内のチケット欄（#tickets）へ移動するだけ。
- 正確な住所・地図・緯度経度・構造化データは載せていない。

- 正式URL（例：/uwasabanashi/ 配下）へ移し、noindex と `X-Robots-Tag` を外す。sitemap・llms.txt に登録し、OGP（正式メインビジュアル納品後）を設定する。
- 共通ヘッダー・フッター（著作権表記・問い合わせ窓口）を既存サイトのものに差し替える。
- 10月31日（土）の追加開催は現在非掲載。確定したらカレンダーと開演時刻リストに追加する。
- 公演データ（src/data/events/）への登録は、販売先・開催日を公式で確認してから。

## 公開前確認事項（デザイン書き出しの一覧）

### 差し替え待ちの素材・リンク（index.astro 冒頭の定数で入力）
- RESERVE_URL：チケット販売先URL（未設定のときボタンはページ内の日程欄へ移動するだけで、外部にはリンクしない）
- KV_SRC：メインビジュアル（未設定時は文字組みで代替）
- LOGO_SRC：支給済みロゴ（未設定時は導入演出に仮のテキストロゴを表示。H1はテキストのまま）
- 会場写真：公開範囲・撮影ルール・所在地特定のおそれを確認し、EXIF位置情報を削除してから掲載
- OGP：正式メインビジュアルの納品後に設定
- 共通ヘッダー・フッター：既存サイトのものに差し替え

### 確定後に入力する項目（未入力の間は表示しない）
- DURATION_TEXT：所要時間（受付を含めて約90分／本編約80分か、受付開始から約95分か）
- ACCESS_TEXT：最寄り駅・駅からの所要時間・バス利用の概要
- CAST_TEXT：出演者名（役名・配役は載せない）
