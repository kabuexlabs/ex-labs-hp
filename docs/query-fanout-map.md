# クエリファンアウト対応マップ（2026-09-11）

根拠：Google AI Mode／AIによる概要は1つの検索を複数のサブクエリに分解して同時検索する（query fan-out）。
参考記事の仮説分類（8種）：①曖昧さの解消 ②潜在ニーズ ③詳細の深掘り ④主張の証拠 ⑤エンティティ ⑥関連トピック ⑦セッション文脈 ⑧個別化。
サイト側で対応できるのは①〜⑥。⑦⑧は検索側の状態なので対象外。

## 方針
- 狙いワードごとに①〜⑥のサブクエリを仮定し、それぞれに「1段落で答える箇所」をサイト内に持つ。
- 答えは抽出しやすい形（要点ボックス・FAQ・定義ボックス・表）で、数字は前提つき、主張には出典。
- ⑤エンティティ：会社・代表・公演の事実は Organization／Person／Event の構造化データと本文で一致させる（済）。
- ④証拠：実績の数字は事例ページと確認できる範囲に限定（ヌル・アーデン約1,000枚、頭脳王全公演完売、宿泊予約20件以上、日経・電ファミ掲載）。

## 「要点」ボックスの追加（③深掘り・①曖昧さへの即答）
immersive-cost／immersive-company／madamis-cost／madamis-company／madamis-nazotoki-chigai／event-hiyou／taikengata-company の7本に、記事冒頭へ3行の要点を追加。凍結中の柱ページ（immersive／madamis／zunousen／shinrisen／shisetsu-katsuyo／taikengata-event／shuyu-event／botsunyukan／saiji）と保護対象（immersive-tokyo）は本文冒頭に手を入れず、FAQ 追加のみ。

## 今後の運用
- 新規記事は執筆時に①〜⑥のサブクエリを3つ以上想定し、それぞれの答えを本文の独立した段落か FAQ に置く。
- GSC で表示される複合語（例：没入 没頭 違い、頭脳戦 英語、催事 読み方）はサブクエリの実例。順位が10位以下のものから順に「答えの段落」を用意する。
- 9/21 以降、柱ページの凍結解除後に要点ボックスを追加する。
