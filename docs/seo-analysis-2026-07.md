## 対応不要と判断したもの

- **技術面**: canonical・OGP・構造化データ（Organization/FAQPage/BreadcrumbList/
  Event/DefinedTerm）・sitemap・robots.txt・AIクローラー許可は整備済みで問題なし。
- **/hacktale/event/zunouou/**（「頭脳王 2026」CTR 1.9%）: チケット完売表記が
  クリックを抑制しているが、イベントは 8/1 終了のため対応の費用対効果が低い。
- **ブランド系クエリ**（exlabs、作品名）: 1〜3位・高CTRで健全。

## リポジトリ外で推奨する施策（今後）

1. **被リンク獲得**: B2B系クエリ（謎解き研修・チームビルディング）は競合が強く、
   コンテンツ改善だけでは1ページ目到達が難しい。導入企業の事例記事化、
   PR TIMES配信時の自社サービスページへのリンク、業界メディアへの寄稿が有効。
2. **ブログでの記事量産**: 「商業施設 集客イベント アイデア10選」のような
   リスト記事は microCMS ブログ側で出すと獲得しやすい（ガイド/サービスページへ内部リンク）。
3. **Search Console の継続観測**: 今回の変更の効果は2〜6週間で順位に反映される。
   特に /guide/immersive/ が10位台→1ページ目に入るかを追う。
4. **作品名クエリのCTR**: 「ブルーダイヤの不在証明」(5.3位・CTR 7.3%) は予約サイト・
   ストア系が上位。作品ページに公演情報・レビューを足すか、店舗ページからの
   リンクを整理すると改善余地あり。
